# Vishnuvardhan Madireddi — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design and theme
- `script.js` — navigation, animations and theme toggle
- `assets/profile.jpg` — supplied profile photo

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `portfolio`).
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will provide your public portfolio URL.
